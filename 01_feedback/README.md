# 深度学习基础实验

本项目包含多个深度学习算法的实现示例，从基础的神经网络到卷积神经网络（CNN），用于学习和理解深度学习的核心概念。

## 项目结构

```
dl_01/
├── fb_01_regression.py              # 回归任务：学习正弦函数
├── fb_02_classify.py                # 分类任务：二分类问题
├── fb_03_classify_flower.py         # 多分类任务：鸢尾花分类（3分类）
├── cnn_04.py                        # CNN实现：手写数字识别
├── rnn_05.py                        # RNN实现（待实现）
├── visualize_softmax.py             # Softmax函数可视化工具
├── visualize_im2col_patch.py        # im2col可视化工具
├── visualize_im2col_patch_dynamic.py # im2col动态可视化工具
├── requirements.txt                  # 项目依赖
└── README.md                         # 项目说明
```

## 环境要求

- Python 3.7+
- numpy >= 1.20.0
- matplotlib >= 3.3.0
- scikit-learn (用于数据集加载)

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行示例

### 1. 回归任务（学习正弦函数）

```bash
python fb_01_regression.py
```

该脚本训练一个神经网络来学习 `sin(x)` 函数，使用反向传播算法进行训练。

**网络结构：**
- 输入层：1个神经元
- 中间层：3个神经元（使用sigmoid激活函数）
- 输出层：1个神经元（恒等函数）

**训练参数：**
- 训练轮数：2001
- 学习率：0.1
- 每200轮显示一次训练结果

### 2. 分类任务（二分类）

```bash
python fb_02_classify.py
```

该脚本训练一个神经网络进行二分类，学习将数据点分类到正弦曲线的上方或下方。

**网络结构：**
- 输入层：2个神经元（x, y坐标）
- 中间层：6个神经元（使用sigmoid激活函数）
- 输出层：2个神经元（使用softmax激活函数）

**训练参数：**
- 训练轮数：101
- 学习率：0.1
- 每10轮显示一次训练结果

### 3. 多分类任务（鸢尾花分类）

```bash
python fb_03_classify_flower.py
```

该脚本使用鸢尾花数据集进行三分类任务，识别三种不同的鸢尾花品种。

**数据集：**
- 样本数量：150个
- 特征数量：4个（花萼长度、花萼宽度、花瓣长度、花瓣宽度）
- 类别数量：3个

**网络结构：**
- 输入层：4个神经元
- 中间层：6个神经元（使用sigmoid激活函数）
- 输出层：3个神经元（使用softmax激活函数）

### 4. 卷积神经网络（手写数字识别）

```bash
python cnn_04.py
```

该脚本实现了一个完整的CNN网络，用于识别8×8像素的手写数字（0-9）。

**数据集：**
- 样本数量：1797个
- 图像大小：8×8像素
- 类别数量：10个（数字0-9）

**网络结构：**
- 卷积层：使用im2col实现卷积操作
- 池化层：最大池化
- 全连接层：用于最终分类
- 输出层：10个神经元（使用softmax激活函数）

**核心特性：**
- 实现了im2col和col2im函数，用于高效的卷积操作
- 完整的反向传播实现
- 训练过程可视化

## 代码说明

### 基础神经网络（fb_01, fb_02, fb_03）

这些文件实现了：
- **MiddleLayer**：中间层类，包含前向传播、反向传播和参数更新
- **OutputLayer**：输出层类，包含前向传播、反向传播和参数更新
- 完整的反向传播训练流程
- 训练过程可视化

### CNN实现（cnn_04）

- **im2col函数**：将图像转换为列矩阵，用于高效的卷积计算
- **col2im函数**：将列矩阵转换回图像，用于反向传播
- **卷积层**：使用im2col实现卷积操作
- **池化层**：最大池化和平均池化
- **完整的CNN训练流程**

## 可视化工具

- `visualize_softmax.py`：演示Softmax函数的工作原理
- `visualize_im2col_patch.py`：可视化im2col转换过程
- `visualize_im2col_patch_dynamic.py`：动态可视化im2col转换

## 注意事项

- 运行脚本时会弹出matplotlib图表窗口，需要手动关闭才能继续
- 训练过程可能需要一些时间，请耐心等待
- CNN训练可能需要较长时间，建议使用GPU加速（如果可用）
