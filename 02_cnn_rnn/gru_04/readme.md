这段代码用纯 NumPy 实现一个简单的 GRU 来拟合带噪声的 
sin
⁡
sin 序列，并可视化训练误差与预测曲线。整体流程：

数据准备：在[−2π,2π]上采样生成 
sin，加高斯噪声；用长度为 n_time 的滑动窗口构造输入 input_data，并用下一时刻作为 correct_data。
GRU 层 (GRULayer)：包含更新门、重置门和候选记忆的前向计算；反向传播手写梯度并累计到 grad_w/grad_v，用于参数更新。
输出层 (OutputLayer)：线性层（恒等激活），预测下一时刻的数值；反向传播计算梯度。
训练 (train)：对序列做时间展开，先前向得到各时刻的门值与隐状态，再从输出层反传到 GRU 层，最后按学习率更新参数。
预测 (predict)：用当前窗口输入逐步滚动预测下一步。
误差与可视化：每 interval 轮打印误差并绘制真实曲线与递推预测曲线；训练结束后画误差随 epoch 的变化。
核心目标：用 GRU 学习时间序列的动态规律，实现对下一步 
sin
⁡
sin 值的拟合与可视化对比。

GRU 是 Gated Recurrent Unit（门控循环单元），一种循环神经网络单元。它通过更新门和重置门控制历史信息的保留与遗忘，结构比 LSTM 更简单，训练更快，常用于时间序列与文本序列建模。
